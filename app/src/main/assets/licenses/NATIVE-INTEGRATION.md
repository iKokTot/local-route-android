# Встраивание локального движка (обязательная процедура перед релизом)

1. Зафиксировать конкретные commit SHA ByeDPI и hev-socks5-tunnel, проверить их
   лицензии и все вложенные third-party notices.
2. Вендорить исходники (не готовые неизвестные `.so`) и собрать их Android NDK
   для всех публикуемых ABI. ByeDPI получает только `127.0.0.1` и локальный
   SOCKS-порт; hev получает только TUN file descriptor от `VpnService`.
3. Реализовать `NativeTunnelBridge` так, чтобы он передавал выбранные
   `DpiStrategy.nativeArguments`, умеет корректно закрывать дескриптор и не
   содержит URL/учётных данных внешнего сервера.
4. Добавить точные SHA, полный текст MIT-лицензий и notices в этот каталог;
   проверить `LICENSE` и экран «О программе» перед распространением APK.
5. На физическом устройстве проверить отсутствие сетевых соединений приложения
   к чему-либо кроме локального сокета и целевых соединений из TUN.

Нельзя подменять эту интеграцию удалённым прокси, «облачной проверкой» или
fallback-сервером: это изменит смысл `LOCAL_DPI` и потребует отдельного режима
`SECURE_TUNNEL` с явной конфигурацией пользователя.
