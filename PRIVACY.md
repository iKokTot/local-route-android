# Политика конфиденциальности Local Route

Дата обновления: 17 октября 2026 года. Версия приложения: 0.22.0.

Local Route — бесплатное Android-приложение с локальным DPI, Telegram-прокси
и VLESS-подключением к серверу пользователя. В нём нет
учётных записей, рекламы, аналитики, телеметрии и SDK для отслеживания.

## Какие данные обрабатываются

Приложение хранит только на самом устройстве профиль, выбранные сервисы,
исключения VLESS, закрытые подсказки и последнюю вручную подтверждённую стратегию.
VLESS-ссылка и секрет Telegram-прокси хранятся в зашифрованном хранилище Android.
Список установленных приложений с иконкой запуска используется локально для
выбора исключений и никуда не передаётся. Журнал
диагностики существует только в памяти приложения и не отправляется разработчику
или третьим лицам.

При включении Local Route Android показывает стандартное системное разрешение
VPN. Это нужно для создания **локального** TUN-интерфейса и передачи трафика в
локальный SOCKS/DPI-движок либо, при явном включении VLESS, на указанный
пользователем сервер. Оба маршрута используют один TUN. В режиме `LOCAL_DPI` внешний VPN-сервер, прокси или
сервис сбора данных не используются; IP-адрес пользователя не скрывается.

## Передача данных

Приложение не отправляет персональные данные, журналы, статистику, содержимое
трафика или идентификаторы устройства на серверы Local Route, поскольку таких
серверов и аналитических SDK нет. Обычные сетевые запросы приложений на телефоне
в локальном DPI-режиме направляются их обычным адресатам через сеть пользователя.

При включённом VLESS трафик, кроме локально выбранных DPI-сервисов и исключений,
проходит через сервер из пользовательской ссылки. Владелец этого сервера и его
провайдер могут видеть сетевые метаданные; Local Route не управляет такими
серверами и не предоставляет готовых ссылок. DNS остального трафика идёт через
DoH внутри VLESS, DNS известных локальных DPI-доменов — напрямую через исходную
сеть. Это не гарантия анонимности или отсутствия утечек при сбоях Android VPN.

Telegram-прокси слушает только loopback телефона и может использовать сторонние
CF-ретрансляторы, резервное прямое подключение либо активный DPI/VLESS-маршрут.
Список доменов ретрансляторов загружается из открытого проекта
<https://github.com/Flowseal/tg-ws-proxy>; есть встроенный резервный список.
Ретрансляторы не принадлежат Local Route. Данные Telegram остаются зашифрованными,
но операторы промежуточных узлов могут видеть IP-адреса и сетевые метаданные.
Запросы для проверки соединения отправляются только для работы выбранного режима.

Ссылки ТГ, МАКС и GitHub открываются только по нажатию и подчиняются политикам
соответствующих сервисов. Никакие журналы не отправляются автоматически.
Пользователь может сам скопировать журнал; VLESS URI/UUID в диагностике маскируются,
но сетевые адреса могут присутствовать. Перед передачей проверьте содержимое.

## Сторонние компоненты и контакты

Список компонентов и лицензий находится в
[`app/src/main/assets/licenses/NOTICE.md`](app/src/main/assets/licenses/NOTICE.md).
Исходный код: <https://github.com/iKokTot/local-route-android>.

По вопросам конфиденциальности и удаления локальных данных: удалите приложение
в настройках Android; это удалит его локальное хранилище. Для связи используйте
раздел Issues в репозитории исходного кода.
# Подписки серверов (0.23)

По кнопке обновления приложение обращается к указанному пользователем HTTPS-источнику
подписки. Источник получает IP и обычные метаданные HTTPS-запроса. Адрес подписки
и полученные VLESS-профили хранятся зашифрованно на устройстве. Фонового обновления
нет. Проверка подключения делает HTTPS-запрос к example.com через выбранный сервер.
