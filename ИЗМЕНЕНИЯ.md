# Local Route Community 0.24.1 — изменения для передачи разработчику

Итоговая версия Windows и Android: **0.24.1**, Android versionCode **25**. Дата: 17 октября 2026 года.

Исходные точки: desktop друга 0.14.1 → наша доработка 0.15.2 → Community 0.24.0 → 0.24.1; Android друга 0.23.0, commit `385096497ea6061cfff8c01edc9b8b6397104b00` репозитория iKokTot/local-route-android → Community 0.24.1. Ниже перечислены накопленные изменения, а не только последний патч. Сетевые ядра сторонних проектов сохранены.

## Интерфейс и управление

- Переработан desktop: отдельные страницы компонентов, три плитки обзора, единый стиль, понятные состояния подключений, согласованные кнопки запуска и остановки.
- Android переведён с прежних экранов Compose на тот же адаптивный HTML/CSS/JavaScript-интерфейс, что используется в Windows. Общие SVG-иконки и каталог сервисов тоже единые.
- Вкладки: «Обзор», «DPI» с молнией, «Telegram» с самолётиком, «VPN» со щитом. В узком окне одна колонка, прокрутка содержимого и нижняя навигация.
- Размер плиток увеличен после обратной связи: крупнее текст, иконки и кнопки; три плитки по-прежнему рассчитаны на первый экран телефона. Для низких экранов есть более компактная раскладка.
- Страницы компонентов упорядочены: подключение, настройки, обратная связь. Общие параметры и ссылки проекта вынесены в отдельные настройки.
- Исправлен возврат: из настроек открывается исходная страница компонента; Android «Назад» сначала закрывает диалог, затем возвращает из настроек и только потом в обзор.
- Черновики настроек сохраняются явно, активный профиль защищён от случайного редактирования; исправлены сбросы, выбор .exe и отображение сохранённой стратегии.

## VPN и подписки

- На обеих платформах можно импортировать отдельный VLESS URI или HTTPS-подписку со списком серверов. Поддерживаются обычные и Base64-списки VLESS, в том числе Reality.
- Вместо единственного сервера добавлена библиотека: до 16 групп по 64 сервера, выбор сервера, обновление одной или всех подписок, удаление отдельной подписки. Остальные группы сохраняются.
- Существующий одиночный список переносится автоматически. Ошибка импорта или обновления не уничтожает сохранённую библиотеку.
- После импорта основной экран показывает список серверов; новая подписка добавляется небольшой кнопкой через диалог. Настройки сайтов располагаются ниже.
- При импорте есть ограничения времени и размера ответа, проверка формата и безопасная обработка ошибок. Неподдерживаемые протоколы пропускаются с сообщением.
- Исправлена передача Reality fingerprint/uTLS и ALPN; Windows проверяет конфигурацию sing-box до сохранения.
- Добавлена диагностика VLESS через временный локальный прокси: отдельно проверяются сервер и выбранные сайты; запрос не должен незаметно обходить проверяемый VPN напрямую.

## DPI, Telegram и маршрутизация

- В Windows сохранён подбор по набору из 22 стратегий: сохранённая проверенная стратегия пробуется первой; улучшены отмена, DNS-повторы и отображение результатов.
- На Android добавлена последовательная ручная проверка четырёх встроенных профилей ByeDPI и необязательной своей команды. Это кандидаты для проверки в конкретной сети.
- Новый сценарий Android: «Начать проверку профилей» → проверить видео/голос → «Работает — сохранить» либо «Не работает — следующий». На последнем кандидате — «Не работает — остановить».
- Следующий кандидат использует другую команду, одинаковые команды исключаются. Прогресс сохраняется при возвращении из YouTube/Discord. До подтверждения кандидат не записывается как рабочий; после исчерпания списка цикл не начинается сам собой.
- При одновременной работе домены включённого DPI направляются в локальный DPI, затем применяются правила VPN. Локальная сеть и явные исключения обходят туннель. В режиме «Весь интернет» оставшийся внешний трафик идёт в VPN.
- Android объединяет DPI и VPN в одном VpnService с ByeDPI/libbox, учитывая ограничение платформы на один VPN. Windows использует отдельные движки WinDivert/Zapret и sing-box. Доменная логика согласована; реализации стратегий зависят от платформы.
- Telegram использует TGWs; сохранены отдельное управление и совместный запуск. Уточнены прямые исключения, поведение DNS и перестроение VPN-маршрутов при переключении DPI.
- Улучшены правила сайтов/приложений, обработка IPv4/IPv6, пользовательских доменов, исключений и поиск приложений. На Android выбираются пакеты приложений, в Windows — .exe.

## Надёжность и хранение

- Согласованы запуск, остановка, отмена, трей и автозапуск; запоздавший результат операции не должен возвращать уже остановленное состояние. На Android отменённое включение не запускается после позднего системного разрешения VPN.
- В Windows добавлены атомарная запись настроек, резервная копия и восстановление с предупреждением; неизвестная версия формата не перезаписывается молча.
- Подписки и серверные секреты хранятся зашифрованно: Electron safeStorage в Windows, шифрованное хранилище Android. Секретные URI не передаются в общий интерфейс.
- Улучшены таймауты внешних команд, обработка DNS, отмена проверок, поиск конфликтующих прокси/туннелей и ограничение объёма журналов.
- Из журналов и экспорта диагностики удаляются секреты, включая значения, разбитые между порциями вывода.
- Усилены CSP, проверка IPC и запрет посторонней навигации. Android WebView загружает только локальные ресурсы, не имеет доступа к произвольным файлам, а нативный мост принимает только известные команды.

## Сборки и исходники

- Обе платформы имеют номер 0.24.1 и название Community. Android использует отдельный пакет `org.localroute.community`; исходное приложение друга может оставаться установленным отдельно.
- Архив Windows содержит готовую portable-программу, движки, полный код приложения в `resources/app`, тесты и документацию.
- Архив Android содержит подписанный APK, исходники с нативными зависимостями и копию общего интерфейса `shared-ui`, инструкции сборки и тесты. Лицензии и авторство сохранены.
- Приватный ключ подписи, пароли, локальные настройки и пользовательская подписка не передаются. Друг может собрать APK со своим ключом; для обновления уже установленного Community APK нужен исходный Community-ключ.

## Проверено и что проверить вручную

Полный набор Windows/общего интерфейса: 80 тестов успешно; JavaScript прошёл проверку синтаксиса. Android: итоговые числа unit-тестов и результат установки приведены в соседнем файле «ПРОВЕРКИ.md». Проверяется совпадение общих ресурсов внутри APK и Windows. Навигация проверена на Pixel 7 без запуска сетевых движков.

Нужно проверить в своей сети: видео YouTube, голос/видео Discord, последовательное отклонение профилей, сохранение рабочего профиля, совместный DPI/VPN, приоритет доменов и переподключение после смены сети/сна. HTTP-проверка сама по себе не доказывает работу видео и голоса. Автотесты не подтверждают обход блокировок конкретного провайдера.

Ограничение: поддерживается VLESS; Hysteria2 и другие протоколы из смешанной подписки пропускаются. Обещания работы каждого DPI-профиля во всех сетях нет. Новые сетевые ядра с нуля не писались.
