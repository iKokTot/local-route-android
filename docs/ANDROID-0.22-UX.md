# Android 0.22 — контекстные настройки и исключения VLESS

## Изменения

- «Настроить» на DPI / Telegram / Сервер открывает соответственно настройки
  DPI / TG / VLESS. «Все настройки» возвращает к общему списку режимов.
- Настройки DPI: сервисы, профиль/проверка, плитка, журнал. Настройки TG:
  инструкция подключения, плитка и свой журнал. VLESS: ссылка, исключения,
  плитка, диагностика. Пользовательских исключений в DPI нет.
- Исключения применяются Android Builder только при создании TUN с включённым
  VLESS. Значение берётся из новой конфигурации ДО startOrReloadService, а не
  из старого plan, поэтому выключение VLESS восстанавливает охват DPI сразу.
  Правила/протоколы движков не менялись; это единственная правка маршрутизации.
- Каталог: 22 рекомендуемых приложения, источники:
  VLESS-EXCLUSIONS-SOURCES.md. Исправлены ID Ozon и ВТБ. Наличие карточки в
  RuStore не означает доказанной несовместимости с VPN.
- Существующий ручной список и пустой список сохраняются. Редактор позволяет
  добавить рекомендации явным действием и сохранить. Отсутствующие пакеты
  игнорируются. При DPI без сервера сохранение списка не перезапускает VPN.
- Компактная панель ТГ / МАКС / GitHub доступна в настройках и «О приложении».
  Адрес MAX предоставлен пользователем: https://max.ru/channel_LocalRoute.
- Помощники при первом посещении каждого режима объясняют следующий шаг,
  закрываются «Понятно» и сохраняют это локально независимо для каждой вкладки.
  Общее первое знакомство и повторный доступ к справке сохранены.
