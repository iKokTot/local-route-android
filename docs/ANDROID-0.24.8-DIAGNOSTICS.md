# 0.24.8 — локальный журнал и копирование отчёта

19 октября 2026. Сборка для воспроизведения ошибок на телефоне, без публикации в магазинах.

- «Настройки → Диагностика и ошибки → Скопировать отчёт». Отчёт содержит журнал, версию/пакет, Android/модель, состояния режимов, тип транспорта и результат проверки связи. Не содержит списка всех установленных приложений или полного профиля.
- Хранилище: закрытая папка приложения `files/diagnostics/errors.txt`, AtomicFile; до 500 событий и 120000 символов. Запись объединяется с задержкой 350 мс, не блокирует обработчик сетевых сообщений. AllowBackup по-прежнему false. Файл не отправляется автоматически.
- Маскирование выполняется до помещения в буфер, до записи и при копировании: URI подключений, HTTPS-ссылки, UUID, bearer-токены, поля паролей/секретов и длинные шестнадцатеричные ключи. Сетевые адреса ошибок могут остаться; это явно объясняется в интерфейсе.
- Core логирует INFO для контекста. Последние 128 идентификаторов соединений (до 4 строк каждого) держатся только в RAM; в постоянный журнал попадает контекст того же ID вместе с предупреждением/ошибкой. Успешные соединения отдельно на диск не сохраняются. Debug-сборки сохраняют прежний уровень DEBUG.
- Ошибки UI-команд, события DPI/VPN и журналы/проверки TG используют общее хранилище. «Очистить журнал» требует подтверждения и не изменяет серверы/профили.
- Буфер обмена на Android 13+ помечен чувствительным, чтобы Android не показывал текст отчёта/прокси-ссылки в предпросмотре.

Проверено: 59 модульных тестов, 15 release UI/хранилища, 2 последовательных instrumentation-теста с force-stop процесса между записью и чтением. Проверены контекст одинакового connection ID, исключение постороннего ID, ограничение размера, очистка буфера, маскирование на диске и в буфере обмена, отмена очистки, повторное открытие интерфейса. Сборка и lintVital успешны.

Это изменение диагностики. Причина ошибки ChatGPT ещё не установлена и не считается исправленной. Старые сообщения из памяти предыдущей версии восстановить нельзя: после установки требуется воспроизвести проблему заново.
