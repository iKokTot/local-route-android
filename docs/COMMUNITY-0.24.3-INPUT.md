# Community 0.24.3: настройки и добавление подключения

Причина: несохранённые маршруты запрещали импорт подписки, а сохранение маршрутов
требовало выбранного сервера. На пустом профиле возникала взаимная блокировка.

- Импорт, ввод подписки и выбор сервера больше не зависят от несохранённых маршрутов.
- Настройки маршрутов сохраняются и без подключения; пустая строка не создаёт профиль.
- Выбор сервера не сбрасывает редактируемые маршруты.
- Для новых настроек выбран весь интернет. Явно сохранённый выбор пользователя сохранён.
- При работающем VPN изменение подключения по-прежнему заблокировано до остановки.

Проверки: 46 модульных тестов и 3 UI-теста на эмуляторе API 37 прошли,
подпись release-сборки проверена. Регрессионный Android-тест
проверяет доступность формы при несохранённых маршрутах, ввод, настоящий импорт
тестовой VLESS-ссылки через нативный мост, выбор и сохранение. Тестовая ссылка
не предназначена для подключения; это проверка интерфейса и хранилища, не сети.

APK использует тот же пакет org.localroute.community.preview и сертификат,
что Community Test 0.24.2, и обновляет эту тестовую сборку без удаления данных.
