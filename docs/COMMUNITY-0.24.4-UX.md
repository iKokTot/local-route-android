# Community 0.24.4 — простой Android-поток

- Одна форма «Добавить подключение»: VLESS URI, HTTPS-подписка или список URI.
- Подключение сохраняется при импорте/выборе; отдельного сохранения в настройках нет.
- Android использует весь интернет через сервер с исключениями. Старые выборочные
  настройки больше не применяются, но их значения не удаляются из хранилища.
- Локальная сеть, приоритет DPI и отдельный путь Telegram остаются прежними.
- Исключения находятся на вкладке VPN; при совместном DPI/VPN они обходят весь TUN,
  поэтому это явно описано. Для DPI без VPN список исключений не применяется.
- Проверка серверов временно запускает туннель, выбирает узел с HTTPS-ответом
  и выключает серверный компонент, сохраняя независимый DPI.
- Нет пустой галочки успеха и кнопок оценки DPI до активной ручной проверки.
- Пустой VPN не показывает обновление, удаление, запуск и проверку без сервера.
- Удаление всех подключений требует подтверждения. Выход из настроек DPI/TG
  с изменениями предлагает отменить выход или отказаться от изменений.
- Android-правки применяются отдельно; Windows-приложение не изменялось.

APK: тот же пакет Community Test и сертификат, что 0.24.2/0.24.3.
Проверки: 46 модульных тестов, 4 UI-теста API 37 и 2 сетевых теста прошли.
Сетевые тесты передают данные через настоящий TUN/WebSocket к локальному
VLESS-стенду и проверяют исключение приложения при DPI/VPN и возврат в туннель.
Проверена подпись release APK; экран VPN осмотрен по снимку эмулятора.
Работа конкретной подписки, провайдерской блокировки и пользовательского Telegram
не доказывается UI-тестами; проверяется отдельно в реальной сети.
