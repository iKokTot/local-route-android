# Local Route Android 0.24.17

6 ноября 2026 года.

Обновлены libbox 1.14.4, Telegram-прокси 2.7.0, сетевой адаптер HEV 2.19.3 и
экспериментальный OpenFlux 0.17.1. Новые библиотеки адаптированы к Android-интерфейсам;
проверки запуска и остановки HEV учитывают результат нативного вызова.

Рабочий ByeDPI 0.13 и строка DPI сохранены. Кандидат 0.17.3 не прошёл повторный
смешанный HTTPS-сценарий. Контрольное сравнение с заменой только libbyedpi.so
подтвердило успешную работу прежнего ядра. Во всех трёх архитектурах доставляемый
libbyedpi.so побайтно совпадает с 0.24.16.

Telegram продолжает работать самостоятельно. Проверка медиарежима получает
публичный MTProto-ответ; в журнале теста подтверждено соединение CF HTTP/2.
Аккаунт, сообщения и файлы пользователя не используются для тестирования.

Включены изменения 0.24.16: предложение новых совместимых версий при открытии,
ручная проверка в настройках и ссылка https://t.me/localroutedpi.

Пакет: org.localroute.community.preview, versionCode 41, Android 8.0+.
Подпись прежняя. Данные сохраняются при установке поверх того же пакета.
При другом пакете приложение устанавливается отдельно.

Проверки: 72 модульных теста без ошибок; финальный сетевой прогон — 21 тест
без ошибок (155.7 секунды). Дополнительно прошли тест OpenFlux, 20 автоматических
сценариев WebView и 5 тестов обновлений. Ручной сценарий Chrome/ChatGPT с профилем
владельца намеренно не запускался. Итого 47 автоматических сценариев эмулятора.
HTTPS проверяется с контрольным запросом без VPN к доступному публичному узлу;
ответ HTTP 403 считается подтверждением TLS/HTTP, а не полной доступности сервиса.

История решений и границы тестирования: [ENGINE-UPGRADE-0.24.17.md](ENGINE-UPGRADE-0.24.17.md).
OpenFlux проверяется с локальным зашифрованным выходным узлом. Работа через
Yandex/Telemost в ограниченной мобильной сети и производительность на реальном
ARM-телефоне в этот прогон не входят. Серверы и подписки приложение не предоставляет.
