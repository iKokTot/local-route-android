# Local Route Android 0.14.0

## Изменения

- Три вкладки DPI / TG / VLESS. Проверка DPI — внутренний экран DPI.
- VLESS направляет интернет всего устройства; старый выбор приложений удалён
  из UI, модели и сервиса, прежние сохранённые списки не применяются.
- Три независимые плитки быстрых настроек: DPI (сохранённая стратегия),
  TG Proxy (постоянный локальный прокси), VLESS (сохранённая ссылка).
  Повторное нажатие останавливает режим. Запуск одного VPN останавливает другой.
- Плитки различаются молнией, самолётом и щитом, включая компактную шторку.
  В уведомлениях используется белый знак маршрута Local Route. Обычная иконка
  приложения имеет светлый мятный фон вместо тёмного; есть monochrome-ресурс.
- TG: сняты принудительное закрепление только WS и лишние IP override для DC.
  Возвращена обычная цепочка WS -> MTProto TCP как на desktop. Публичные
  прокси/CF-списки не используются.
- TG использует SOCKS активного DPI либо аутентифицированный loopback-SOCKS
  VLESS. При изменении режима автоматически перезапускается с прежним секретом.
  Пароль SOCKS VLESS временный, в журнал не попадает; no-auth подключения запрещены.
- Проверка TG запускается автоматически и требует resPQ. «Порт открыт» и
  «Есть связь» разделены, ошибка проверки отображается как «Нет связи».

   отсутствие SOCKS-пароля в локальном журнале.

## Границы результата

Тайм-ауты в присланном журнале относятся к соединению с адресами Telegram.
Fallback и прохождение через DPI/VLESS исправлены и проверены на эмуляторе,
но доступность тех же адресов у оператора пользователя этим не подтверждается.
Вход в Telegram, все медиа/DC и звонки требуют проверки на телефоне. Если IP
Telegram блокируются целиком, нужен доступный VLESS-сервер, а не только DPI.
Конкретная пользовательская VLESS-ссылка и работа на ARM-устройстве не проверялись.
