# Android 0.24.7 — стабильность и понятное подключение

Дата: 18.10.2026. Версия подготовлена для отдельной тестовой установки и обновления RuStore.

## Изменения 1–6

1. Запуск движка отделён от проверки связи. VPN показывает результат последней HTTPS-проверки; изменение сети и маршрутов сбрасывает его. Ответ тестового узла Telegram не называется проверкой чатов, аккаунта или звонков.
2. Сохраняется единый TUN с независимыми командами DPI/VPN и отдельным TG-сервисом. При аварийном выходе DPI сначала предпринимается восстановление серверного маршрута без DPI; при неудаче общий VPN останавливается с уведомлением.
3. Выбор физической сети предпочитает системный физический default, затем прежнюю проверенную сеть. Callback вторичной сети не переключает маршрут произвольно. Потерянная сеть явно исключается, даже если Android ещё возвращает её в allNetworks. При смене сети обновляются underlying network и DNS; повторная компиляция маршрутов отложена на 750 мс и объединяет события. Telegram переподключает локальный мост при возвращении сети.
4. Сбой/пустой ответ загрузчика не изменяет сохранённую библиотеку. Обновления групп собираются перед одной записью. Если выбранного сервера больше нет в подписке, он сохраняется отдельной подписанной группой, а не заменяется автоматически непроверенным сервером. Пустое legacy-значение выбора трактуется как отсутствие выбора.
5. Исключения дополнены установленными launcher-приложениями: локальные названия, иконки и поиск. Рекомендации для отсутствующих приложений явно помечены. Не используются QUERY_ALL_PACKAGES и выгрузка списка на сервер. Исключения обходят общий Android TUN, следовательно и DPI при совместном режиме.
6. Сохранён единый редактор VLESS/HTTPS/списка и последовательность «добавить → выбрать → подключить». Не добавлены новые протоколы или бесплатные серверы. Пошаговый первый запуск начинается с VPN; интерфейс не обещает работу всех приложений по результату одного теста.

## Проверки и ограничения

- Модульные проверки выбора сети, состояния проверки связи, парсеров и маршрутизации.
- UI-проверки единственного редактора, ошибок импорта, поиска/иконок исключений, гида, крупного текста и навигации.
- Проверки хранилища: удаление выбора при явном удалении группы, сохранение выбора при обновлении, пустое legacy-значение, пересоздание зашифрованного хранилища.
- Сетевой стенд использует локальный VLESS/WS fixture и отдельный UID networkprobe. Он не является общедоступным VPN и не доказывает обход блокировок оператора.
- Сценарии сети: потеря/возврат подключения, независимое выключение режимов, исключения, быстрые команды/ошибочная конфигурация, отрицательная HTTPS-проверка, остановка TG при работающих DPI/VPN и короткая блокировка экрана.
- Release UI проверяется отдельно; сетевой стенд требует debug-вариант с видимостью тестового provider. В эмуляторе используются изолированные пакеты, чтобы не удалять данные ранее установленного приложения с другой подписью.
- Финальный APK: org.localroute.community.preview, versionCode 31, версия 0.24.7. Подпись совпадает с опубликованной 0.24.6.
- Для RuStore тот же код собирается с `-PapplicationId=org.localroute.android` и прежним магазинным ключом. Пакет совпадает с 0.22.0 (versionCode 22); ключ SHA-256 `30bf353ac2f7ab8826e05f4eaa6214279c6bb8a21fd81c45b0970c2a32e6ae15`. Это отдельный APK, не тестовый preview-пакет.
- Реальный Wi-Fi → сеть оператора, длительный Doze и несколько часов фоновой работы на устройствах разных производителей ещё требуют проверки. Короткий тест блокировки экрана этого не заменяет.

Точные результаты итогового прогона и APK находятся в локальном outputs/android-0.24.7.
