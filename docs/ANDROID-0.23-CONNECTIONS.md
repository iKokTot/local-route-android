# Android 0.23 — подключения

Настройки серверного режима принимают отдельный VLESS, список строк, обычный
или URL-safe Base64 и HTTPS-ссылку на такой список. Список и адрес подписки
хранятся в том же зашифрованном хранилище, что и действующий профиль.
Старый одиночный профиль мигрирует без изменения ключа. Обновление выполняется
явной кнопкой; автоматического фонового опроса нет. Ошибка загрузки сохраняет
предыдущий список. Импорт заменяет список, активный URI остаётся отдельным.

Загрузчик: проверка сертификата системная, только HTTPS, без перенаправлений,
тайм-ауты 10 секунд, предел 512000 байт, до 64 кандидатов. Неподдерживаемые
протоколы и произвольный JSON движка не импортируются. Пустой импорт отклонён.
Ссылка подписки может содержать секрет; в UI скрыта и в журнал не попадает.

Выбор сохраняет URI; существующие CombinedVpnService, исключения и TG gateway
продолжают использовать его без отдельного VPN-сервиса. При активном сервере
редактирование и выбор заблокированы. DPI можно оставить включённым.

Автоподбор запускается явно: сохранённый URI первым, остальные последовательно.
Каждый кандидат запускается существующим VPN-путём с разрешением Android;
проверка идёт через аутентифицированный SOCKS gateway, TLS с проверкой имени
example.com и HTTP 200. Первый ответивший остаётся включённым и сохранённым.
При неудаче восстанавливается прежний URI. Это проверка одного сайта, не
гарантия доступности всех сервисов. Перебор кратко меняет маршрут телефона.

Ручной адрес без протокола/ключа, WireGuard, OpenVPN, Clash, сторонние закрытые
форматы не поддерживаются. Бесплатность приложения не предоставляет серверы.
