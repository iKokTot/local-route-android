# Android 0.20 — регрессия 0.19 и исключения

Пользователь подтвердил: на телефоне оба режима показывают «включён», но доступ
не работает. Это опровергает готовность 0.19 для его телефона. Успешный эмуляторный
fixture не подтверждает обход провайдера, конкретную VLESS-ссылку или OEM Android.
Причина конкретного сбоя пока не установлена: телефонного журнала ещё нет.

Найдены и изменены риски:

1. Отдельный DPI в 0.19 зависел от package/SNI-правил, иначе трафик шёл напрямую.
   Это регрессия относительно общего локального SOCKS-пути. В 0.20 отдельный DPI
   не использует package/sniff и по умолчанию идёт в local-dpi, кроме LAN и
   приложений, исключённых Android. Внешний сервер не используется.
2. Отдельный VLESS возвращён к VlessConfigCompiler до объединения. Совместный
   режим остался отдельной конфигурацией в том же сервисе, без второго VPN.
3. DNS выбирался из первой любой NOT_VPN сети, даже без INTERNET; IPv6 с zone
   вроде fe80::1%wlan0 отвергался проверкой. Теперь сначала активная физическая
   INTERNET сеть, затем validated, затем доступная. Предпочитается IPv4 DNS,
   scoped/link-local IPv6 не переносится в конфигурацию без интерфейса.
   Эти дефекты не доказывают причину данного пользовательского случая.
4. Старый «включён» означал только запущенный движок, а журнал ядра пользователю
   не показывался. Добавлен ограниченный in-memory журнал warning/error ядра,
   доступный на обеих вкладках даже при статусе запуска без ошибок. Нет телеметрии.

## Исключения

Используется Android VpnService.Builder.addDisallowedApplication, не хрупкий
список доменов. Отмеченное приложение целиком вне TUN и использует обычную сеть.
По умолчанию добавлены известные пакеты нескольких банков, Ozon/Wildberries.
Пользователь может снять/добавить галочки в списке установленных launcher apps.
QUERY_ALL_PACKAGES не запрашивается. Пустой список сохраняется именно пустым.
Настройка общая для DPI/VLESS, применяется через reload без потери URI/стратегии.
Неизвестный или отсутствующий пакет не ломает запуск. Разные версии банков
нужно отметить вручную. Сайты внутри общего браузера не исключаются этим способом.
При Android lockdown прямой выход исключённых приложений блокируется системой.

## Честный критерий завершения

Сборка и эмулятор проверяют конфигурацию, TCP/UDP и фактический обход TUN для
исключённого тестового UID. Проверка на том же телефоне/сети остаётся обязательной.
Не объявлять проблему устранённой только по результату этих тестов.
Ничего не публиковалось; Windows и APK предыдущих версий сохранены.

Документация: https://developer.android.com/develop/connectivity/vpn
и https://sing-box.sagernet.org/configuration/dns/server/udp/.
