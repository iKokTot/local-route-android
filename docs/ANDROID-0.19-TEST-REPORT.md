# Android 0.19.0 — совместный DPI/VLESS

Дата: 2026-10-17. Изменения локальные; публикация, push и обновление RuStore не выполнялись.
Windows-версия и ранее выданный APK 0.18.0 не изменены.

## Реализация

Один CombinedVpnService и один libbox/gVisor TUN. Отдельно управляемые флаги
DPI и серверного маршрута. Выбранные YouTube/Discord определяются по пакету
Android и известным доменам и направляются в локальный ByeDPI SOCKS5;
остальной трафик — через VLESS, если он включён, иначе напрямую.
Собственный пакет исключён из TUN для предотвращения петли.

Интерфейс, плитки и уведомление используют одни команды. Остановка DPI
оставляет сервер; остановка сервера оставляет DPI. Есть отдельное действие
«Выключить всё». Некорректная новая ссылка не разрушает работающий профиль.
Сохранённый активный endpoint не перечитывается при простой остановке DPI.
Команды сериализованы; завершение старого экземпляра сервиса не сбрасывает новый.
Готовность локального SOCKS проверяется рукопожатием, выход worker отслеживается.

Исправлена существенная ошибка lifecycle: libbox вызывает serviceStop при
перезагрузке конфигурации. Этот callback закрывает старый TUN/core, но не
должен ставить в очередь остановку самого Android-сервиса после reload.
Сверено с SFA BoxService, GPL-3.0-or-later; attribution включён в APK.

восстановления с обязательным настоящим ответом fixture, а не только флагом UI.
Первоначальные неуспешные прогоны не считаются подтверждением готовности.

## Ограничения и проверка на телефоне

- Совместный режим требует Android 10+; на Android 8/9 режимы только отдельно.
- Reload кратко прерывает существующие соединения; бесшовность не обещается.
- DNS известных DPI-доменов идёт напрямую, остальной при VLESS — через DoH
  сервера. Это не полная изоляция DNS всех неизвестных доменов выбранного пакета.
- Доменные правила браузера могут не охватывать неизвестные CDN, IP-only и ECH.
- Нет постоянного kill switch после остановки/гибели Android VPN; это не
  приложение с гарантией анонимности или отсутствия утечек при сбоях.
- Эмулятор не воспроизводит блокировки провайдера и ограничения прошивки телефона.
  Нужны видео YouTube, голос/медиа Discord, Telegram и смена Wi-Fi/мобильной сети
  на реальном устройстве с рабочей пользовательской VLESS-ссылкой.
- Проверка Telegram resPQ не доказывает работу всех DC, медиа и звонков.
- Остальные форматы ссылок и подписки не добавлялись в рамках этой версии.
