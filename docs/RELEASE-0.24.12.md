# Local Route 0.24.12 — новый логотип

Обновление оформления поверх 0.24.11. Сетевые функции и компоненты не изменялись.

- Единый знак для DPI, proxy и VLESS в интерфейсе и на значке приложения.
- Обновлены адаптивная, монохромная иконки Android и значок уведомления.
- Обновлены SVG и PNG общего интерфейса.

Публичный APK: Android 8.0+, пакет `org.localroute.community.preview`, versionCode 36, подпись сохранена.
Пакет отдельный от RuStore. Устанавливайте APK поверх предыдущей публичной сборки; при конфликте не удаляйте приложение без сохранения подключений.

Сборка соответствующих исходников:

```powershell
gradle :app:assembleRelease -PapplicationId=org.localroute.community.preview -PreleaseSigningFile=<path-to-your-signing-properties>
```

Используйте собственный файл подписи. Ключи и пароли в репозиторий не входят.
GPL-3.0; сведения о сторонних компонентах — LICENSE, NOTICE.md и инструкции репозитория.
Для VPN нужны собственная VLESS-ссылка или подписка с VLESS-серверами. Работа зависит от сети и сервера.
