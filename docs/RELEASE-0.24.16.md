# Local Route Android 0.24.16

6 ноября 2026 года.

- При открытии приложение проверяет обновления на GitHub, не чаще раза в сутки.
- На обзоре появляется небольшая карточка: скачать, напомнить через сутки,
  пропустить конкретную версию. В настройках есть ручная проверка и ссылка на
  найденное обновление, даже если карточка отложена или версия пропущена.
- Проверка не блокирует запуск и остановку DPI/VPN/Telegram. Отсутствие сети
  отображается в настройках и не прерывает работу приложения.
- Обновления фильтруются по пакету, версии, сертификату подписи и версии Android.
  Черновики, тестовые выпуски и выпуски без проверяемых метаданных не предлагаются.
- Скачивание открывает страницу выпуска. Установку подтверждает пользователь.
- Обновлена ссылка Telegram: https://t.me/localroutedpi.

Пакет APK: org.localroute.community.preview; versionCode 40, Android 8.0+.
Для обновлений следующих выпусков нужно приложить local-route-update.json,
созданный из готового подписанного APK. См. [UPDATES.md](UPDATES.md).
В 0.24.15 и более ранних APK проверка обновлений отсутствует — сначала нужно
вручную установить 0.24.16 с совпадающими пакетом и подписью.

Проверка работает при открытом приложении. Системных push-уведомлений и службы
проверки в фоне нет. Внешних публикаций в рамках этой доработки не выполнялось.

Проверки: 71 модульный тест и 26 тестов на эмуляторе (21 сценарий интерфейса,
5 проверок совместимости выпусков, отсрочки, пропуска и отсутствия сети).
Метаданные создаются из подписанного APK; подпись совпадает с 0.24.15.
