# Android 0.21 — интерфейс без изменения рабочих движков

Основание: пользователь подтвердил работу 0.20 и попросил сделать интерфейс
понятнее, вынести настройки и оставить запуск в лёгком доступе.

## Решение

- Три прежних режима: DPI / Telegram / Сервер. Активность одного не скрывает другой.
- Один основной переключатель режима, закреплённый непосредственно над нижней
  навигацией. При выполнении команды — прогресс, повторное нажатие заблокировано.
- Главная вкладка показывает состояние, одну короткую подсказку и необходимые
  действия. Telegram предлагает подключение в клиенте только после запуска прокси.
- Общие настройки — отдельный экран с разделами, не длинная лента форм:
  подключение к серверу, сервисы DPI, исключения, плитки, диагностика, о приложении.
- Ссылка скрыта по умолчанию, черновик сохраняется при смене вкладок. Изменять
  ссылку нельзя при активном сервере. Есть явное сохранение и подтверждение.
- Подробные ограничения/приватность — в справке; ошибки не скрываются.
  Вводное знакомство один раз, начиная с VLESS. Повторный доступ из настроек.
- Тёмная мятная палитра и фирменный знак сохранены. Элементы Material, нажатия
  минимум 48dp, основные кнопки 56dp, вертикальные действия для крупного шрифта.
- Android Back возвращает из раздела, затем из настроек; переходы не вызывают
  остановку сервисов.

Принципы: стабильная навигация, одна доминирующая задача, видимость состояния,
progressive disclosure, узнавание вместо запоминания и достаточная зона нажатия.
Это практическое применение, а не утверждение об изучении «всех законов UX».

Источники: https://m3.material.io/components/app-bars/ и
https://support.google.com/accessibility/android/answer/7101858.

## Границы изменения

Сетевой код и настройки подключения не менялись. Все native .so release APK
сверены по SHA-256 с 0.20 и совпадают. Никаких публикаций и push.
GPL/notices сохранены, новых зависимостей нет. Старый APK 0.20 сохранён.
