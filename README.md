# Local Route Community 0.24.1

Исправление общего интерфейса Windows и Android, 17 октября 2026 года.

## Один интерфейс на обеих платформах

Android теперь показывает ту же адаптивную страницу, что Windows. Общие HTML, CSS, JavaScript, SVG-иконки и каталог сервисов находятся в `resources/app/src/renderer` десктопного проекта. Gradle копирует их в APK задачей `prepareSharedUi`. Нативные экраны Android 0.23 больше не используются.

Разделы одинаковые: **Обзор, DPI, Telegram, VPN**. DPI обозначен молнией, Telegram — самолётиком, VPN — щитом. Обзор компактный: три плитки помещаются на первом экране телефона. На страницах компонентов следуют блоки подключения, настроек и обратной связи; прокручивается содержимое, нижняя навигация остаётся на месте.

Ссылки проекта и общие параметры доступны через небольшую кнопку «Настройки». Возврат ведёт на исходную страницу компонента. На Android системная кнопка «Назад» сначала закрывает форму подписки, затем возвращает из общих настроек, затем ведёт в обзор.

## Подписки и серверы

Большая форма появляется только при нажатии «Добавить подписку». После импорта основное место занимает список серверов, сгруппированных по подпискам. Можно добавить несколько подписок, выбрать сервер, обновить одну или все подписки и удалить конкретную подписку. Остальные группы сохраняются. Старый единственный список читается без ручного переноса. Ошибка загрузки не заменяет сохранённые группы.

Поддерживается VLESS в обычном или Base64-списке, до 64 серверов в группе и до 16 групп. Другие протоколы, включая Hysteria2, пропускаются. Адреса подписок и URI серверов хранятся зашифрованно; в интерфейс передаются только названия, адреса серверов, порты и непрозрачные идентификаторы.

## Платформенная часть

На Windows сохранены Electron, WinDivert/Zapret и sing-box. На Android общая страница работает в WebView с локальными ресурсами; нативный мост управляет существующим единым VpnService, ByeDPI, libbox, TGWs и шифрованными настройками. Удалённые страницы и ресурсы WebView не загружает.

Сетевые приоритеты сохранены: локальная сеть и явные исключения; домены включённого DPI; правила VPN; прямой выход. В режиме «Весь интернет» оставшийся внешний трафик идёт в VPN. Домены DPI остаются локальными.

В Android остаются необходимые отличия: пакеты приложений вместо .exe, строка ByeDPI вместо WinDivert-стратегий, системное разрешение VPN и плитки шторки вместо автозапуска Windows. Результат локального DPI подтверждается пользователем после проверки реального видео или голоса. Автоматически успешным он не помечается.

## Установка

Windows: завершите прежнее приложение через трей и запустите `Local Route.exe` из папки новой версии от администратора. Настройки хранятся отдельно от дистрибутива. Рабочий VPN компьютера во время подготовки сборки не переключался.

Android: установите `Local-Route-Community-0.24.1.apk` поверх Community 0.24.0. Пакет прежний — `org.localroute.community`, ключ подписи тот же. Установленные настройки сохраняются. Исходный APK друга имеет другой пакет и остаётся отдельным приложением.

На Pixel 7 пользователя версия 0.24.1 уже установлена. Проверены общий интерфейс, положение плиток, работа кнопки «Назад» и сохранность состояний и профилей при навигации. Сетевые движки в этой проверке не включались. Полную работу DPI/VPN в сети пользователя нужно проверять отдельно.

## Исходники

Итоговый Windows-архив содержит готовую portable-программу с движками, исходники в `resources/app`, тесты и общий интерфейс. Итоговый Android-архив содержит APK, нативный проект и `shared-ui` для автономной сборки. Если рядом расположен десктопный проект 0.24.1, Gradle берёт интерфейс из него; иначе использует `shared-ui`.

Ключ подписи и `release-signing.properties` не включены в архивы. Для следующих обновлений установленного APK необходим тот же Community-ключ. Для самостоятельной сборки можно использовать свой ключ.

Лицензии и авторство исходной Android-основы iKokTot/local-route-android, commit `385096497ea6061cfff8c01edc9b8b6397104b00`, сохранены. Android-код распространяется по GPL-3.0-or-later. Прежние документы 0.24.0/0.15.2 оставлены как история; актуальное описание — этот файл.

## Проверка DPI на Android

Нажмите «Начать проверку профилей», проверьте реальное видео/голос и выберите «Работает — сохранить» или «Не работает — следующий». Последняя кнопка на последнем кандидате остановит DPI. Одинаковые команды исключены; до подтверждения вариант не считается рабочим. Накопленный список изменений находится в «ИЗМЕНЕНИЯ.md».
